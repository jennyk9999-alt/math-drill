# 연산 도장

초등 1학년부터 중학 3학년까지의 연산을 **96개 기술 · 15단계**로 쪼개서 훈련하는 웹앱.
계정도, 서버도, 인터넷도 필요 없습니다. 파일 하나로 돌아갑니다.

## 이 앱이 다른 점

- **속도가 통과 조건입니다.** 기술마다 목표 시간이 있고, 정답 5연속 + 반응속도 중앙값이 목표 이내여야 숙달로 인정합니다. 맞히기만 해서는 통과하지 못합니다.
- **문제를 매번 새로 만듭니다.** 고정된 문제 세트가 없어서 답을 외울 수 없습니다.
- **약한 기술이 더 자주 나옵니다.** 정확도와 속도를 함께 보고 출제 비중을 조절합니다.
- **틀리면 답이 아니라 방법을 알려줍니다.** `8 + 5`를 틀리면 "8에 2를 주면 10, 5는 2와 3으로 갈라져요 → 10 + 3 = 13"처럼 그 숫자에 맞춘 설명이 나옵니다.
- **오답은 그날 안에 다시 나옵니다.** 2문제 뒤에 같은 문제가, 8문제 뒤에 같은 유형의 새 문제가 나옵니다.
- **진단 테스트 2분**으로 시작 단계를 정합니다. 잠긴 단계도 눌러서 미리 연습할 수 있어서 학교 진도에 맞출 수 있습니다.

## 쓰는 법

`index.html`을 브라우저에서 열면 끝입니다. 휴대폰에서는 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.

- 키보드: 숫자키, `Enter` 확인, `Backspace` 지우기, `-` 부호, `.` 소수점, `Tab` 칸 이동, `?` 힌트
- 기록은 그 브라우저에만 저장됩니다. 설정 화면에서 백업 문자열을 복사해 다른 기기로 옮길 수 있습니다.
- 학습자를 여러 명 등록할 수 있습니다.

## 고칠 때

**`app.body.html`이 원본입니다.** `index.html`은 거기에 `<head>`/`<body>` 껍데기를 씌워 만드는 생성물이니 직접 고치지 마세요.

```bash
{ cat head.part; cat app.body.html; printf '</body>\n</html>\n'; } > index.html
```

문제를 추가했다면 브라우저 콘솔에서 생성기를 전수 검산해 보세요. 식을 그대로 계산해서 답과 대조하는 방식으로 96개 기술 × 수백 회를 몇 초 만에 확인할 수 있습니다.
